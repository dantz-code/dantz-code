## 👨‍💻 Sobre mim

Sou estudante de **Sistemas de Informação na PUC Minas**, atualmente no **3º período**, e estou construindo minha formação para atuar como **desenvolvedor full stack**.

Tenho uma base em **C#**, **Programação Orientada a Objetos**, **SQL**, banco de dados relacional, HTML, CSS, Git e GitHub. Neste momento, estou aprofundando meus conhecimentos em **JavaScript** e, posteriormente, pretendo avançar para **TypeScript**, **Node.js**, APIs e **React**.

Também tive experiência profissional com sistemas e dados na área da saúde, realizando análise e correção de cadastros, validação de informações e identificação de inconsistências. Essa experiência reforçou meu interesse em utilizar a tecnologia para resolver problemas reais e melhorar processos que impactam pessoas.

Atualmente, busco uma oportunidade de **estágio em desenvolvimento de software**, na qual eu possa aplicar meus conhecimentos, aprender com projetos reais e continuar evoluindo na prática.
